# F3 验收基线

- Standalone 在 Core、Community、Keycloak 全部不可用时仍能完成生成、预览和下载。
- Official 未登录、邮箱未验证、年龄门槛未满足或额度不足时不能开始渲染。
- 每个会话默认最多三次渲染，并发请求和重试不会绕过次数或重复扣费。
- 候选不可公开枚举，24 小时清理；对话实际在 30 天清理。
- 最终文件严格验证为 Java 64×64 PNG 并保存哈希、模型和双层元数据。
- 机器审核失败不发布；成功确认通过用户主体自动发布并返回 Community resource ID。
- 自部署社区接入使用 PKCE 和最小 scope，不含静态平台主密钥。
- 提供商故障可重试、退款或进入人工处理，不产生不可解释扣费。
- 两种模式均有端到端测试和契约测试。
