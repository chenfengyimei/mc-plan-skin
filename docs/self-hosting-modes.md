# 自部署模式契约

## Standalone 必需能力

- 部署者配置一个受支持的远程模型适配器与密钥。
- 用户无需 MC Plan 账号即可创建会话、生成候选、预览和下载最终 PNG。
- 本地部署者自行决定认证、配额和保留策略，并必须向其用户真实说明。
- 不配置官方社区时，应用不显示失效入口、不发起外部请求。

## 可选官方社区接入

- 部署者注册公开 OIDC 客户端和允许的精确回调地址。
- 浏览器使用 Authorization Code + PKCE，用户明确授权最小 scope。
- 令牌保存在安全会话边界，不写入日志、URL 或浏览器长期明文存储。
- 官方 Community 可独立限流、撤销客户端和拒绝不合规文件。

## Official 必需能力

- 用户必须登录并完成邮箱验证与年龄门槛声明。
- 开始创作前消费每日额度或积分。
- 界面在第一次实际渲染前明确说明确认成品后自动公开。
- 成品确认后不能提供绕过 Community 发布的“私密官方下载”路径；未来私有通道需独立产品与隐私决策。

同一构建产物通过运行时配置选择模式。禁止维护 Official 专有源码分支。
