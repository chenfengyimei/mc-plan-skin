# Q-001 基准候选路线可比指标口径（SKIN-009 能力预留记录）

状态：指标口径文档。本工作流不实施基准本身；Q-001 路线决议已由 **ADR-0015**（`mc-plan-foundation/decisions/0015-skin-visual-acceptance-route-concept-bridge.md`，2026-10-13 落档）记录，正式厂商绑定保持未决。

## 两条候选路线

1. **文本直出 v4**：文本模型直接输出 v4 逐像素蓝图 → 确定性渲染器（`LlmStructuredSkinProvider`，SKIN-008 交付，受控基准已证伪 flash 档：四次成功评分 1.5/2/4/1，详见 ADR-0015 事实链）。
2. **概念图 → 视觉 → v4**：图像模型依描述产概念图 → 视觉模型读图提取 v4 蓝图 → 确定性渲染器（`ImageConceptSkinProvider`，本工作流交付的**能力预留**：fake|llm|image Provider 注册、ImageClient 与视觉提取双抽象、同一 ProviderAdapter 接缝可插拔）。

两条路线共享同一 v4 协议（色温守门、行补丁精修、边界兜底）与 skin-validator 全量校验，业务层零改动感知 Provider 类型。

## 受控基准可比指标口径（两路线同口径归集）

- **有效皮肤率**：N 次受控生成中通过 skin-validator 全量校验（64×64、Steve/Alex 双层、overlay 非空）的比例；分母计入全部失败与重试（worker 重试上限 3 含首次），原始调用与受控生成双口径如实入账。
- **编辑一致性**：同一描述多次生成的语义稳定性——调色板/服饰位置与描述逐词对齐通过率；v4 色温守门触发率与循环内一次重绘成功率分别记录。
- **延迟**：每候选端到端耗时；概念图管线两跳分记（图像生成 / 视觉提取）。
- **成本**：按厂商计费单位归集（ProviderUsage 的 inputUnits/outputUnits 透传）；不预设任何厂商价格（Q-013 未决，禁止硬编码成本数值）。
- **地区与数据条款**：模型部署区域、数据留存与训练使用条款；未绑厂商期间逐候选记录。
- **视觉评分**：沿用 SKIN-008 记录锚点（提示词语义、双层对齐、脸部工艺、非模板感），**最终视觉验收由项目所有者终裁**。

## 基准执行边界

- 受控基准需要所有者授权的预算与凭据（key 只经 gitignored `apps/worker/.env` 注入，绝不入 Git/日志/输出）。
- 基准结果与正式厂商绑定由所有者视觉验收 + 新 ADR 决定（ADR-0015「变更条件」）；本工作流交付的是厂商中立扩展点，生产环境继续拒绝非基准适配器实例化。
